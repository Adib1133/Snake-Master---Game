# 🐍 Snake Master

A futuristic neon-style Snake game built with pure HTML, CSS, and JavaScript. Snake Master combines classic arcade gameplay with modern visuals, particle effects, combo systems, power-ups, difficulty modes, animated UI panels, sound effects, and responsive controls.

---

# 🎮 Features

## Core Gameplay
- Classic Snake gameplay with smooth controls
- Grid-based movement system
- Progressive difficulty scaling
- Combo scoring system
- Multiple food types with unique effects
- Power-ups and loot system
- Obstacles at higher levels
- Lives system
- Pause and resume support

## Difficulty Modes
### 🐢 Easy
- Wall wrap enabled
- 5 lives
- Slow movement speed
- Casual gameplay experience

### 🐍 Medium
- Hard walls
- 3 lives
- Balanced speed
- Standard gameplay mode

### 💀 Hard
- Hard walls
- 1 life only
- Fast movement speed
- High challenge mode

# 🧠 Gameplay Systems

## Combo System
Eating food rapidly builds a combo multiplier.
Higher combos award bonus points.

## Level System
- Levels increase every 50 points
- Game speed gradually increases
- Obstacles begin spawning at higher levels

## Leaderboard
- Local leaderboard stored in browser localStorage
- Tracks top scores
- Session statistics included

## Session Statistics
- High score
- Longest snake
- Maximum combo
- Total games played
